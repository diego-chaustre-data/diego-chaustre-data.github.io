## Cómo trabajo

La IA escribe rápido, pero no conoce el negocio ni responde por los datos.
Mi trabajo es dirigirla, cuestionarla y verificar lo que produce.
Hoy escribo SQL fundamental por mi cuenta (SELECT, agregaciones, JOIN) y sigo avanzando cada semana.

Todos los datos que aparecen en las demostraciones son ficticios.
